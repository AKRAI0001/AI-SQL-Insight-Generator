# AI-Powered SQL Insight Generator

An AI-powered application that converts natural language into SQL queries using Google's Gemini 2.5 Flash model and generates human-readable insights from SQLite databases.

---

## Features

- Natural Language to SQL
- AI Generated Insights
- SQLite Database Support
- Streamlit User Interface
- Prompt Engineering
- Interactive Dashboard

---

## Tech Stack

Python

SQLite

Streamlit

Google Gemini 2.5 Flash

Git

---

## Project Workflow

User Question

↓

Gemini converts Question to SQL

↓

SQL executes on SQLite

↓

Database returns Result

↓

Gemini explains Result

---

## Installation

git clone <repo>

pip install -r requirements.txt

streamlit run app.py
